# P4 App 内内容货架和阅读器

状态：未开始  
建议分支：`codex/reader`  
责任范围：`ios/WorthyScroll/**`、`ios/WorthyScrollShared/**`、`docs/workstreams/reader.md`

## 目标

把当前 Web 原型里的“未读库存”和“站内阅读”迁移成 iOS 原生体验。

## 验收标准

- [ ] 首页展示未读内容流。
- [ ] 支持搜索、来源筛选、已读状态。
- [ ] 点击内容进入 App 内阅读页。
- [ ] 阅读页不跳转外部平台。
- [ ] 阅读进度和已读状态可记录。
- [ ] 成功提交并推送本功能块。

## 步骤

- [ ] 创建内容货架 Tab。
- [ ] 创建内容卡片和列表状态。
- [ ] 创建 App 内 Markdown 阅读页。
- [ ] 接入本地缓存数据。
- [ ] 写入阅读事件。
- [ ] 更新本日志勾选状态并提交推送。

## 接口依赖

- 内容同步功能提供 `ContentRepository`。
- 反馈功能提供点赞、拉踩、隐藏、已读动作。
