# Web 原型和批注协作

状态：进行中
建议分支：`codex/web-prototype`
责任范围：`src/**`、`README.md`、`docs/workstreams/web-prototype.md`

## 目标

让浏览器原型成为可真实点击、可阅读、可批注的产品评审环境，方便在进入 iOS 原生实现前快速标注和调整交互。

## 接口依赖

- Web 原型内容数据来自 `public/content-items.json`。
- 组件锚点使用 `data-annotation-target` 和 `data-annotation-label`，后续新增可评审组件时应同步补齐。
- 本地 Codex skill 名称：`ui-review`。
