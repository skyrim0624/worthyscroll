# 未读库存 App 视觉方向

## 参考图提炼

这张参考图的核心不是「文件管理器」，而是一个低负担的内容货架：用户一打开就看到可选内容，但没有算法流那种压迫感。

关键设计要素：

- iOS 原生感：状态栏、动态岛、居中标题、左返回、右更多，降低学习成本。
- 浅灰底色：页面背景不是纯白，搜索框和卡片都浮在柔和灰面上。
- 大圆角搜索框：搜索是主入口，但视觉上很安静，不抢内容卡片的注意力。
- 轻量筛选栏：用文字加小箭头表示「全部内容」「最近同步」，不做复杂 tab。
- 视图切换按钮：列表图标弱化，网格图标白底浮起，暗示当前模式。
- 双列卡片：卡片像文件、论文、便签、海报的缩略图，形成「我可以挑一个打开」的心理模型。
- 低对比阴影：卡片有层次，但不做厚重拟物。
- 预览图重于说明文字：用户先被内容形态吸引，再看标题和时间。

## 套到我们的产品

我们的第一版不是短视频替代算法，而是「未读库存货架」。所以视觉上要让用户感觉自己在翻一个私人内容库，而不是被推流追着跑。

当前原型保留了这些结构：

- 顶部标题改成「未读库存」。
- 搜索框沿用参考图的大圆角浅灰样式。
- 筛选栏改成「全部内容 / 最近同步 / 网格视图」。
- 卡片内容使用公众号、视频号、文章、活动、AI 工程笔记等来源。
- 卡片预览用文档、便签、海报、视频缩略图这几种视觉隐喻。
- 底部加「今天 18 分钟」状态胶囊，后续可变成阅读进度或健康替代反馈。

## 后续设计原则

- 不做信息流瀑布，不做无限下滑奖励。
- 卡片可以刷，但每个卡片都要像一个「值得打开的对象」。
- 视觉可以轻松，但不能娱乐化到像另一个短视频平台。
- 内容入口优先表达来源、质量和可读时长，而不是点赞、热度、评论。
